## The keyboard investigation (run this next)
The Windows exe prints a `keyboard diagnostics` line once/second while control is on Kali,
with: `grabbed`, `kbd_seen`, `kbd_swallowed`, `kbd_passed_to_windows`, `kbd_borrow_fail`,
`mouse_hook_calls`, `raw_samples`. Run **two conditions**, cross to Kali and type + Alt+Tab in
each, capture ~15 s of lines:
- **A — normal (not admin).**
- **B — Run as Administrator** (UAC prompt; user approves).

Decode:
- `kbd_seen` flat while typing → hook not firing (timeout/removed).
- `kbd_seen` rises, `kbd_swallowed` flat, `grabbed=false` → gate desync (mouse motion is gated
  on `suppress` on the raw thread; keyboard on `grabbed` on the hook thread — unify them).
- both rise, `grabbed=true`, keys STILL leak, **and B (admin) works** → **UIPI/elevation**
  (leading suspect, matches the Alt+Tab clue). Fix: ship an admin manifest
  (`requestedExecutionLevel level="requireAdministrator"`).
