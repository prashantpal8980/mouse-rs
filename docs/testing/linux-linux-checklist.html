Same-OS test checklist

Kali ↔ Linux Mint first, then Windows ↔ Windows. Press Done or Problem on each line. If something goes wrong, write what you saw and the time in the box. Your ticks are saved in this browser. When you finish, press Copy results and paste them to Claude.

Test files
  • On Kali: already made, in /home/kalip/mouse/test-files/from-kalip. Claude opened it for you.
  • On Mint open Terminal and type wget -qO- 192.168.122.1:8002/f | sh. The O is a capital letter O. This makes the same set in a mouse-test-files folder on Mint's Desktop. Run it again after every Mint restart, because the live session forgets files.

Each set: 1 a note · 2 a file with a strange name · 3 a folder 3 levels deep with an empty folder inside · 4 a folder of 300 small files · 5 a 5 MB file · 6 a 300 MB file · and checksums, used to prove the big files arrived intact.

Always paste on the other computer's Desktop (click an empty spot, then Ctrl+V).
