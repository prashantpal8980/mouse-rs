What you need to do next

  1. Unplug the Ethernet cable while sharing. Sharing should come back over Wi-Fi within a few seconds. Then plug it back in and check it moves back to the cable. If Wi-Fi does not work, allow mouse-rs through Windows Firewall on that network.
  2. Copy a file on Windows and paste it on Kali. The send side is proven. A file arriving and pasting is not.
  3. Copy a file, quit mouse-rs on Kali, then paste it in Thunar. Proves the clipboard holder keeps files pasteable after exit.
  4. When a file is waiting on Windows, look for a toast. The notification exists in code and has never been seen on the laptop.
  5. Login-screen test, when you can reboot. On hold at your request.
